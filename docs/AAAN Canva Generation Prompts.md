# AAAN Canva Generation Prompts

Nov 12, 2026 · @Jak Softwares

Every photo and video in the AAAN Photo & Video Asset Library, as a ready-to-paste prompt for Canva. The IDs (P001, V01) match the library, so each generated file can be named and tracked there.

## How to use these prompts in Canva

**For photos:** open Canva's AI image generator (Magic Media or Dream Lab), paste the prompt, choose the format shown in the Canva format column, and generate. Pick the best of the results, then crop to the exact shape in the editor if needed.

**For videos:** Canva makes short clips of a few seconds each. Every video below is split into numbered scenes. Generate each scene as its own clip, then put the clips in order in a Canva video project. Add the voice-over, captions, music and the AAAN logo there.

**Every prompt is complete.** The AAAN look is already written in: warm natural light, true colours, real African settings, dignified and modern, no text or logos. Paste each prompt as it is.

**Keeping the library consistent**

- Generate 4 versions of each prompt and keep the one that looks most like a real photograph.
- Reject any image with garbled text, extra fingers, warped tools, fake-looking logos or plastic-looking skin.
- Keep the look of AAAN staff consistent: dark green polo shirts, plus hairnets, white coats and boots inside plants and labs.
- Use one Canva colour adjustment on every image: slightly warm, slightly richer greens, no heavy filters.
- Name each file by its ID, as in the asset library, for example AAAN\_GH-SEF\_Processing\_P036\_v1.

**Rules**

1. **No children at work.** None of these prompts show children, and none should be added. If a result shows a child, discard it. Buyers check closely for child labour in cocoa and cashew.
2. **Placeholders must be replaced before launch.** Prompts marked *Placeholder* stand in for real AAAN offices, products and staff. They can go into the design, but the real photo must replace them before the site goes live.
3. **No generated faces for named people.** The leadership portraits (P009) must come from a real photo session. A layout placeholder is given instead.
4. **Label generated images in the asset library.** Record "Generated in Canva" and the prompt used, and keep them in the 03 Generated folder.
